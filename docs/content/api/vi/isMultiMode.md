# sremote.isMultiMode
Kiểm tra xem chế độ đa media có đang được kích hoạt hay không.

## Tham số
| Tên tham số | Kiểu dữ liệu | Mặc định | Mô tả |
| :--- | :--- | :--- | :--- |
| `key` | `string` | `null` | Passkey xác thực nếu domain bị khoá. |

## Giá trị trả về
Trả về `boolean` (`true` nếu đang ở chế độ multi mode, `false` nếu là single mode).
