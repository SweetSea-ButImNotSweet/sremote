# sremote.toggle
Chuyển đổi trạng thái phát/tạm dừng của media (nếu đang phát thì tạm dừng, nếu đang tạm dừng thì phát tiếp).

## Tham số
| Tên tham số | Kiểu dữ liệu | Mặc định | Mô tả |
| :--- | :--- | :--- | :--- |
| `instanceId` | `string` | `null` | Định danh của media instance muốn chuyển đổi. |
| `key` | `string` | `null` | Passkey xác thực nếu domain bị khoá. |
