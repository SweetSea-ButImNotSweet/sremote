# sremote.playbackRate
Thiết lập tốc độ phát (playback rate) của media trong iframe hoặc adapter.

## Tham số
| Tên tham số | Kiểu dữ liệu | Mặc định | Mô tả |
| :--- | :--- | :--- | :--- |
| `rate` | `number` | **Bắt buộc** | Tốc độ phát mong muốn (ví dụ: `0.5`, `1.0`, `1.25`, `1.5`, `2.0`). |
| `instanceId` | `string` | `null` | Định danh của media instance muốn áp dụng tốc độ phát. |
| `key` | `string` | `null` | Passkey xác thực nếu domain bị khoá. |
