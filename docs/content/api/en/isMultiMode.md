# sremote.isMultiMode
Checks whether multi-media mode is currently enabled.

## Parameters
| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `key` | `string` | `null` | Passkey authentication if domain lock is enabled. |

## Return Value
Returns a `boolean` (`true` if currently in multi mode, `false` for single mode).
