# sremote.rate / sremote.rate
Sets the playback rate of the media inside the target iframe or adapter.

## Parameters
| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `rate` | `number` | **Required** | The desired playback speed (e.g. `0.5`, `1.0`, `1.25`, `1.5`, `2.0`). |
| `instanceId` | `string` | `null` | Identifier of the media instance to apply playback speed to. |
| `key` | `string` | `null` | Passkey authentication if domain lock is enabled. |
