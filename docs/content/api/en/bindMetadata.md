# sremote.bindMetadata
Assigns custom playback metadata (`title`, `artist`, `album`, `artwork`) to the iframe's MediaSession.

## Parameters
| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `meta` | `Object` | **Required** | Metadata object containing:<br>- `title` (`string`): Title of the track/video.<br>- `artist` (`string`): Artist, channel, or creator name.<br>- `album` (`string`): Album name.<br>- `artwork` (`Array<{ src, sizes?, type? }>`): List of artwork/poster image objects. |
| `instanceId` | `string` | `null` | Identifier of the target media instance. |
| `key` | `string` | `null` | Passkey authentication if domain lock is enabled. |

## Notes
- If `artwork` contains a Blob URL generated by the parent page, SRemote automatically clones and transfers the binary Blob data through the MessagePort channel to bypass Same-Origin Policy (SOP) restrictions.
