# sremote.toggle
Toggles play/pause state of the media (pauses if playing, resumes if paused).

## Parameters
| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `instanceId` | `string` | `null` | Identifier of the media instance to toggle. |
| `key` | `string` | `null` | Passkey authentication if domain lock is enabled. |
