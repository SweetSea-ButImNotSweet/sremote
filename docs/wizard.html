Bước 1: Chuẩn bị Thẻ DOM hoặc Thẻ Iframe

Trước tiên, bạn cần quyết định nền tảng media muốn nhúng. Tùy vào nền tảng, việc cấu hình HTML trên trang của bạn sẽ khác nhau:

Kịch bản 1: Nhúng 22 Nền tảng Phổ biến (YouTube, Spotify, Vimeo, SoundCloud...)

Với gói @sremote/ready2use, bạn không cần tự viết thẻ iframe. Chỉ cần chuẩn bị một thẻ <div> trống làm khung chứa (container), SRemote sẽ tự nạp SDK chính hãng và render thẻ iframe chuẩn xác:

<!-- Tạo vùng chứa video theo tỷ lệ 16/9 -->
<div id="player-box" style="width: 100%; max-width: 720px; aspect-ratio: 16/9; background: #000; border-radius: 8px; overflow: hidden;"></div>

Kịch bản 2: Iframe Cross-Origin không có SDK (Bilibili, Kick, Rumble...)

Nếu dịch vụ bạn dùng không cung cấp Player JavaScript SDK và bạn muốn điều khiển nó thông qua Userscript Bridge, thẻ <iframe> của bạn bắt buộc phải được cấp quyền hợp lệ qua thuộc tính allow:

<iframe
  id="cross-origin-frame"
  src="https://player.bilibili.com/player.html?bvid=BV1xx411c7mD"
  allow="autoplay; encrypted-media; picture-in-picture; fullscreen"
  allowfullscreen
  style="width: 100%; height: 450px; border: none; border-radius: 8px;">
</iframe>
💡 Mẹo về sandbox

Nếu thẻ iframe có khai báo thuộc tính sandbox, bắt buộc phải có tối thiểu sandbox="allow-scripts allow-same-origin allow-presentation allow-forms" để script không bị chặn.

Bước 2: Cài đặt Gói Thư viện Phù hợp

SRemote được chia làm các gói thư viện nhỏ gọn (Tree-shakable) để bạn chỉ cài những gì dự án thực sự cần:

Nhu cầu tích hợp Gói thư viện Lệnh cài đặt Package Manager

</script>

Bước 3: Bắt tay & Khởi tạo (Handshake & Mount)

Kết nối player với bộ điều khiển tập trung SRemote:

Cách 1: Khởi tạo với `@sremote/ready2use` (Khuyên dùng)

Hàm mount() tự động gắn thẻ iframe vào container, nạp SDK nền tảng và liên kết adapter vào SRemote:

import { sremote } from '@sremote/sdk';
import { youtube } from '@sremote/ready2use';

// 1. Gắn YouTube vào container
await youtube.mount('#player-box', {
  videoId: 'dQw4w9WgXcQ',
  playerVars: { controls: 1, autoplay: 0 }
});

// 2. Điều khiển đồng nhất qua sremote:
await sremote.play();
await sremote.seek(15);      // Tua tiến 15 giây
await sremote.volume(0.8);   // Âm lượng 80%

// 3. Lắng nghe tiến độ phát thời gian thực:
sremote.on('timeupdate', ({ state }) => {
  console.log(`⏱️ Thời gian: ${Math.round(state.currentTime)}s / ${Math.round(state.duration)}s`);
});

Cách 2: Quản lý Lifecycle an toàn trong React / Vue SPA

Tránh rò rỉ bộ nhớ (Memory Leak) khi component bị unmount:

// Hàm mount() trả về đối tượng scoped { remote, destroy }
const yt = await youtube.mount(containerRef.current, { videoId: 'dQw4w9WgXcQ' });

// Khi component unmount (React cleanup useEffect hoặc Vue onUnmounted):
yt.destroy(); // Tự động xóa event listener và dọn dẹp thẻ iframe DOM sạch sẽ

🎮 Nhánh 4.1: Tự xây dựng Simple Video / Music Player

Tự thiết kế giao diện điều khiển (Custom Controls) bọc ngoài trình phát nhúng:

<div id="player-box" style="width: 100%; max-width: 640px; aspect-ratio: 16/9;"></div>

<div style="max-width: 640px; margin-top: 10px; display: flex; align-items: center; gap: 10px;">
  <button id="btn-toggle">▶ Play</button>
  <span id="time-text">00:00 / 00:00</span>
  <input type="range" id="seek-bar" min="0" max="100" value="0" style="flex: 1;">
  <input type="range" id="vol-bar" min="0" max="1" step="0.05" value="1" style="width: 80px;">
</div>

<script type="module">
  import { sremote } from 'https://cdn.jsdelivr.net/npm/@sremote/sdk/+esm';
  import { youtube } from 'https://cdn.jsdelivr.net/npm/@sremote/ready2use/+esm';

  await youtube.mount('#player-box', { videoId: 'dQw4w9WgXcQ' });

  const btnToggle = document.getElementById('btn-toggle');
  const timeText = document.getElementById('time-text');
  const seekBar = document.getElementById('seek-bar');
  const volBar = document.getElementById('vol-bar');

  btnToggle.onclick = () => sremote.toggle();

  sremote.on('play', () => btnToggle.textContent = '⏸ Pause');
  sremote.on('pause', () => btnToggle.textContent = '▶ Play');

  sremote.on('timeupdate', ({ state }) => {
    const cur = Math.round(state.currentTime || 0);
    const dur = Math.round(state.duration || 1);
    timeText.textContent = `${cur}s / ${dur}s`;
    seekBar.value = (cur / dur) * 100;
  });

  seekBar.oninput = async () => {
    const dur = (await sremote.getState()).duration || 100;
    const target = (seekBar.value / 100) * dur;
    await sremote.seekTo(target);
  };

  volBar.oninput = () => sremote.volume(parseFloat(volBar.value));
</script>

📜 Nhánh 4.2: Playlist / Podcast Queue

Tự động chuyển sang bài tiếp theo khi bài hiện tại kết thúc (sự kiện ended):

import { sremote } from 'https://cdn.jsdelivr.net/npm/@sremote/sdk/+esm';
import { youtube } from 'https://cdn.jsdelivr.net/npm/@sremote/ready2use/+esm';

const playlist = [
  { title: 'Track 1 - Lofi Chill', id: 'jfKfPfyJRdk' },
  { title: 'Track 2 - Rick Astley', id: 'dQw4w9WgXcQ' },
  { title: 'Track 3 - Synthwave', id: '4xDzrJKXOOY' }
];

let currentIndex = 0;
let playerHandle = null;

async function loadTrack(index) {
  currentIndex = index;
  if (playerHandle) playerHandle.destroy();

  playerHandle = await youtube.mount('#player-box', {
    videoId: playlist[currentIndex].id,
    playerVars: { autoplay: 1 }
  });
  console.log('🎵 Đang phát:', playlist[currentIndex].title);
}

// Bắt sự kiện kết thúc bài -> tự động nhảy bài tiếp theo
sremote.on('ended', () => {
  const nextIndex = (currentIndex + 1) % playlist.length;
  loadTrack(nextIndex);
});

// Điều khiển Next / Prev thủ công:
document.getElementById('btn-next').onclick = () => loadTrack((currentIndex + 1) % playlist.length);
document.getElementById('btn-prev').onclick = () => loadTrack((currentIndex - 1 + playlist.length) % playlist.length);

loadTrack(0);

🎬 Nhánh 4.3: WatchParty / SyncTheater

Đồng bộ play, pause, seek giữa các client qua kênh BroadcastChannel / WebSocket:

import { sremote } from 'https://cdn.jsdelivr.net/npm/@sremote/sdk/+esm';
import { youtube } from 'https://cdn.jsdelivr.net/npm/@sremote/ready2use/+esm';

const channel = new BroadcastChannel('sync_room_theater');
let isBroadcasting = false;

await youtube.mount('#player-box', { videoId: 'dQw4w9WgXcQ' });

function broadcast(action, time = null) {
  isBroadcasting = true;
  channel.postMessage({ action, time, sentAt: Date.now() });
  setTimeout(() => { isBroadcasting = false; }, 300);
}

document.getElementById('btn-play').onclick = async () => {
  await sremote.play();
  broadcast('PLAY');
};

document.getElementById('btn-pause').onclick = async () => {
  await sremote.pause();
  broadcast('PAUSE');
};

channel.onmessage = async (e) => {
  if (isBroadcasting) return;
  const { action, time } = e.data;
  if (action === 'PLAY') await sremote.play();
  if (action === 'PAUSE') await sremote.pause();
  if (action === 'SEEK' && typeof time === 'number') await sremote.seekTo(time);
};

🎓 Nhánh 4.4: EdTech LMS Interactive Video Quiz

Tự động tạm dừng video tại giây thứ 30 và hiển thị modal trắc nghiệm bắt buộc:

import { sremote } from 'https://cdn.jsdelivr.net/npm/@sremote/sdk/+esm';
import { youtube } from 'https://cdn.jsdelivr.net/npm/@sremote/ready2use/+esm';

const CHECKPOINT = 30;
let passedQuiz = false;

await youtube.mount('#player-box', { videoId: 'dQw4w9WgXcQ' });

sremote.on('timeupdate', async ({ state }) => {
  if (!passedQuiz && state.currentTime >= CHECKPOINT) {
    await sremote.pause();
    document.getElementById('quiz-modal').style.display = 'block';
  }
});

window.submitQuizAnswer = async function(isCorrect) {
  if (isCorrect) {
    passedQuiz = true;
    document.getElementById('quiz-modal').style.display = 'none';
    alert('Chính xác! Bạn được tiếp tục bài học.');
    await sremote.play();
  } else {
    alert('Sai rồi, vui lòng thử lại nhé!');
  }
};

🍅 Nhánh 4.5: FocusDeck Pomodoro Ambient Lo-fi

Tự bật nhạc khi làm việc và tự fade-out âm lượng khi hết hiệp 25 phút:

import { sremote } from 'https://cdn.jsdelivr.net/npm/@sremote/sdk/+esm';
import { youtube } from 'https://cdn.jsdelivr.net/npm/@sremote/ready2use/+esm';

await youtube.mount('#lofi-slot', { videoId: 'jfKfPfyJRdk' });

async function fadeOutAndPause() {
  for (let vol = 1.0; vol >= 0; vol -= 0.1) {
    await sremote.volume(vol);
    await new Promise(r => setTimeout(r, 150));
  }
  await sremote.pause();
}

document.getElementById('btn-start-focus').onclick = async () => {
  await sremote.volume(0.8);
  await sremote.play();
  // Hết hiệp 25 phút:
  setTimeout(fadeOutAndPause, 25 * 60 * 1000);
};

📺 Nhánh 4.6: Multi-Streamer Command Center

Xem nhiều luồng stream song song kèm tính năng Solo Audio:

import { sremote } from 'https://cdn.jsdelivr.net/npm/@sremote/sdk/+esm';
import { youtube } from 'https://cdn.jsdelivr.net/npm/@sremote/ready2use/+esm';

await youtube.mount('#stream-1', { videoId: 'dQw4w9WgXcQ' });
sremote.instances.assign('#stream-1', 'cam-1');

await youtube.mount('#stream-2', { videoId: '76979871' });
sremote.instances.assign('#stream-2', 'cam-2');

window.soloAudio = async function(activeCam) {
  ['cam-1', 'cam-2'].forEach(async id => {
    if (id === activeCam) {
      await sremote(id).unmute();
      await sremote(id).volume(1.0);
    } else {
      await sremote(id).mute();
    }
  });
};

⌨️ Nhánh 4.7: Phím tắt Toàn cục (Global Keyboard A11y)

import { sremote } from 'https://cdn.jsdelivr.net/npm/@sremote/sdk/+esm';

window.addEventListener('keydown', async (e) => {
  if (['INPUT', 'TEXTAREA'].includes(document.activeElement?.tagName)) return;

  if (e.code === 'Space' || e.code === 'KeyK') {
    e.preventDefault();
    await sremote.toggle();
  } else if (e.code === 'KeyJ') {
    e.preventDefault();
    await sremote.seek(-10);
  } else if (e.code === 'KeyL') {
    e.preventDefault();
    await sremote.seek(10);
  } else if (e.code === 'KeyM') {
    e.preventDefault();
    await sremote.toggleMuted();
  }
});

📊 Nhánh 4.10: Audio-Driven Slide Deck

import { sremote } from 'https://cdn.jsdelivr.net/npm/@sremote/sdk/+esm';

const cues = [
  { time: 0, slide: 1 },
  { time: 20, slide: 2 },
  { time: 55, slide: 3 }
];

sremote.on('timeupdate', ({ state }) => {
  const cur = state.currentTime;
  const match = [...cues].reverse().find(c => cur >= c.time);
  if (match) {
    document.getElementById('slide-img').src = `/slides/page-${match.slide}.png`;
  }
});
